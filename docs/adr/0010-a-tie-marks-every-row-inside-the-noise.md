# A tie marks every row inside the noise

A chart whose leader sits inside another candidate's noise marked no one (ADR 0008), so next to charts with a marked row it looked like the mark had failed. Now the leader's row and every row inside its noise sit on the wash, and the method line still names whose lead is inside the noise, so a reader sees who shares first. A clear lead still marks one row. The scorecard and the matchup's winner line don't change: the table marks no cell in a tied column, and the line names the tie.

## Considered options

- **No mark on a tie, as ADR 0008 had it.** Rejected: a chart with no marked row reads as broken beside charts that have one.
- **The leader's row alone.** Rejected: the wash would claim a lead the method line calls noise.
